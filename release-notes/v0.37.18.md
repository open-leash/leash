# Leash 0.37.18

Leash 0.37.18 reduces unnecessary security interruptions while keeping
high-confidence secret and destructive-action protections closed.

## Highlights

- Makes DLP, sensitive-access, and blast-radius approvals goal-aware by
  default, with configurable Strict mode for users and Business policy owners.
- Reuses one bounded contextual evaluation across relevant protections to
  avoid duplicate model calls and delays.
- Adds recent conversation context for installed-agent hooks while bounding
  and validating transcript access.
- Stops Codex and Claude background control requests from creating duplicate
  Island activity and completion sounds.
- Replaces full-conversation feature-runtime round trips with a bounded prompt
  context envelope, preventing payload-limit reconnect loops on long Codex
  conversations.
- Reports genuine oversized payloads as HTTP 413 instead of a retryable 503.

## Verification

- Engine, Desktop, Rust proxy, hosted API, and hosted dashboard test suites
  passed.
- Local proxy integration, typechecks, production builds, deployment
  readiness, and product smoke checks passed.
